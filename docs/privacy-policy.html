1. 概述

ChatGPT 对话目录助手（“我们”、“本扩展”）是一款为 ChatGPT（chatgpt.com） 网页提供对话目录与快速导航的浏览器扩展。我们非常重视您的隐私保护，本隐私政策将说明我们如何收集、使用、存储和保护您的信息。

2. 信息收集

2.1 我们收集的信息

  • 对话内容摘要：扩展会在 chatgpt.com 页面读取您作为用户的消息文本，仅用于在侧边栏生成目录与定位；不保存完整会话。
  • 用户偏好设置：包括侧边栏宽度、展开/收起状态、星标标记等本地设置。
  • 本地存储数据：所有数据均通过 Chrome Storage API 存储在您的本地浏览器中。

2.2 我们不收集的信息

  • 不收集任何可用于识别个人身份的信息。
  • 不长期保存完整对话内容，仅保存必要的摘要以便导航。
  • 不收集浏览历史或其他网站数据。
  • 不进行任何形式的用户追踪或分析。

3. 信息使用

我们收集的信息仅用于以下目的：

  • 在侧边栏生成对话目录并实现快速定位。
  • 保存您的个性化设置与偏好，以提升使用体验。

4. 数据存储与安全

4.1 本地存储

  • 所有数据均存储在您的本地浏览器中（Chrome Storage API）。
  • 数据不会上传至任何远程服务器。
  • 数据仅在您使用扩展的设备上可访问。

4.2 数据安全

  • 采用浏览器标准的安全存储机制。
  • 数据传输仅限于浏览器内部。
  • 不涉及第三方收集或广告网络。

5. 权限说明

扩展所需权限及用途如下：

  • storage：用于保存用户设置与本地历史摘要。

站点范围：

  • https://chatgpt.com/*：仅在 ChatGPT 网页上运行。

6. 第三方服务

本扩展不使用任何第三方分析、广告或数据收集服务。所有功能均在本地运行。

7. 用户权利

  • 您可随时卸载扩展以停止数据的本地收集与使用。
  • 您可通过浏览器设置清除扩展的本地存储数据。
  • 您可查看和管理所有本地存储的数据（例如通过扩展的设置或浏览器开发者工具）。

8. 儿童隐私

本扩展不专为 13 岁以下儿童设计，我们不会有意收集儿童的个人信息。

9. 隐私政策更新

我们可能会不定期更新本隐私政策。若发生重大变更，我们会在扩展更新说明中告知您。

1. Overview

ChatGPT Conversation Sidebar (“we”, “this extension”) is a browser extension that provides conversation directory and quick navigation on ChatGPT (chatgpt.com). We care about your privacy. This policy explains how we collect, use, store, and protect your information.

2. Information Collection

2.1 What We Collect

  • Conversation Summaries: Reads your user messages on chatgpt.com solely to build a sidebar directory and navigation; full conversations are not stored.
  • User Preferences: Sidebar width, collapsed state, starred items, and related local settings.
  • Local Storage Data: All data is stored locally via the Chrome Storage API.

2.2 What We Do NOT Collect

  • No personally identifiable information.
  • No long-term storage of full conversation content; only necessary summaries for navigation.
  • No browsing history or data from other sites.
  • No user tracking or analytics of any kind.

3. Information Usage

  • Generate conversation directory in the sidebar and enable quick navigation.
  • Save your personalization settings and preferences to improve user experience.

4. Data Storage & Security

4.1 Local Storage

  • All data is stored locally in your browser (Chrome Storage API).
  • Data is never uploaded to remote servers.
  • Data is only accessible on your device.

4.2 Security

  • Uses browser-standard secure storage mechanisms.
  • Data transmission is limited within the browser.
  • No third-party collection or ad networks involved.

5. Permissions

Required permissions and purposes:

  • storage: Save user settings and local history summaries.

Site scope:

  • https://chatgpt.com/*: Runs only on ChatGPT web pages.

6. Third-Party Services

No third-party analytics, ads, or data collection services. All functionality runs locally.

7. Your Rights

  • Uninstall the extension at any time to stop local collection and use of data.
  • Clear extension data via browser settings.
  • View and manage locally stored data (e.g., via extension settings or browser dev tools).

8. Children’s Privacy

Not designed for children under 13; we do not knowingly collect children’s personal information.

9. Updates

This policy may be updated occasionally. For significant changes, we will notify you in the extension update notes.
